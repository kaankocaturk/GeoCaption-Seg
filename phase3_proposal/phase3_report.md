## Abstract
Semantic segmentation of remote sensing imagery is challenging when visually similar land-cover classes (e.g., grass-land vs. cropland) must be distinguished. This paper investigates whether incorporating textual scene descriptions into a Vision Transformer (ViT) pipeline can improve segmentation accuracy. A multi-modal transformer is designed to fuse patch-level image features with caption embeddings via concatenation-based fusion. Experiments on a 10,000-image remote sensing dataset with seven land-cover classes show that the proposed multi-modal model achieves **0.478 mIoU**, outperforming the image-only baseline (**0.355 mIoU**) by **+0.123 points**. An ablation study across five caption generation strategies reveals that text-only captions provide the strongest supervision signal. Grass-to-Crop confusion is significantly reduced, directly validating the hypothesis that textual context disambiguates visually similar classes.

**Keywords:** *semantic segmentation, multi-modal learning, vision transformer, remote sensing, text-guided segmentation*

## I. INTRODUCTION
Semantic segmentation assigns a class label to every pixel in an image. In remote sensing, classes such as grassland and cropland share similar spectral and textural properties, making pixel-level discrimination difficult with visual features alone [3]. Vision Transformers (ViTs) have demonstrated strong performance on segmentation tasks by modelling long-range spatial dependencies [1]. Concurrently, multi-modal learning has shown that combining vision and language can boost downstream performance in tasks such as image captioning, visual question answering and zero-shot classification [2]. However, the use of free-form textual descriptions to guide dense segmentation remains under-explored. Phase 3 of this study presents the finalized pipeline, comprehensive benchmarking, and discussion.

## II. METHODOLOGY

### A. Dataset
The dataset contains 10,000 remote sensing images (128×128 px) with corresponding pixel-level segmentation masks in seven classes (Tree, Shrub, Grass, Crop, Built-up, Barren, Water). Each image is paired with captions generated by five strategies: `text_qwen3-4b`, `hybrid_gemma3-4b`, `hybrid_qwen3-vl-8b`, `vision_gemma3-4b`, and `vision_qwen3-vl-8b`. An 80/20 train/validation split (8,000 / 2,000 images) is used.

### B. Baseline: Image-Only Transformer
Patch embedding (16×16) projects each image into d=256 dimensional tokens. A Transformer encoder (depth=6, heads=8) processes the sequence; a linear head maps each token to class logits, which are bilinearly upsampled to the original resolution. 

### C. Multi-Modal Transformer
The image encoder is identical to the baseline. A separate text encoder (depth=3, heads=8, d=256) processes tokenized captions with masked mean-pooling, producing a single caption vector projected to d=256. This vector is broadcast to every image patch and concatenated, yielding a 2d-dimensional representation that is fused through a linear GELU LayerNorm layer before the segmentation head.

### D. Training Details
Both models are trained with AdamW (lr=5×10−4, weight decay=1e-4) and CosineAnnealingLR (ηmin=1e−6). The baseline trains for 60 epochs; the multi-modal model for 70 epochs. Data augmentation includes random flips, 90° rotations, and colour jitter. Dice-CrossEntropy loss with inverse frequency class weights is used. Best-model checkpointing is applied based on validation mIoU.

## IV. BENCHMARKING: CAPTION SOURCE ABLATION
Five multi-modal models trained and each using a different caption column, for 30 epochs under identical conditions. The text-only captions (`text_qwen3-4b`) consistently outperform vision-only captions. Text descriptions introduce novel semantic information (land-use context) not already present in the image features, whereas vision-only captions largely reiterate visual properties the image encoder already captures. Hybrid captions fall in between, combining both modalities but potentially introducing noise from redundant visual cues. Caption quality matters: the spread across caption sources demonstrates that the choice of description strategy is a meaningful design decision, not a trivial hyperparameter.

## V. DISCUSSION AND CONCLUSION
The multi-modal transformer consistently surpasses the image-only baseline, with the largest gains on semantically rich classes. The concatenation-based fusion is simple yet highly effective in providing text-driven context to patch-level visual features. 

**Key conclusions:**
1. **Text Matters:** Incorporating text captions into a vision transformer increases the mIoU by +0.123, validating the core hypothesis of the project.
2. **Disambiguation of Similar Classes:** Grass and Crop classes, which suffer from high confusion in image-only models due to similar spectral signatures, benefit the most from textual cues.
3. **Modality Redundancy:** Ablation studies confirm that text-only captions are superior because they provide orthogonal semantic information, whereas vision-derived captions offer redundant information.

**Future Work:** Current limitations include low IoU for rare or hard-to-distinguish classes (Shrub, Built-up) and the absence of pretrained backbones. Future efforts could replace concatenation with cross-attention fusion, integrate a pretrained backbone (SegFormer / DINOv2), and explore deeper text encoders for finer semantic understanding.
