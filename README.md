# DI 725 Term Project: Multi-Modal Transformers for Remote Sensing

This repository contains the implementation of Phase 3 for the DI 725 (Transformers and Attention-Based Deep Networks) Term Project.

## Project Overview
The objective of this project is to apply multi-modal transformer architectures to segment remote sensing data. We explore whether incorporating textual captions generated by large vision-language models (e.g., Qwen-VL, Gemma) can improve the pixel-wise semantic segmentation performance over an image-only baseline.

## Dataset
The dataset consists of remote sensing RGB images, multi-class segmentation masks (7 classes including Tree, Shrub, Grass, Crop, Built-up, Barren, Water), and respective natural language captions. 
**Note:** The dataset (`DI725_project_dataset/`) is excluded from this repository via `.gitignore` to prevent large file uploads and data leakage. Please place the dataset in the root folder before running the notebook.

## Methodology
1. **Baseline Model**: A purely vision-based transformer (ImageSegTransformer) that encodes patches and decodes them into segmentation masks.
2. **Multi-Modal Model**: A vision-language fusion transformer (ImageTextSegTransformer) that concatenates the output tokens of a text encoder (processing the image's descriptive caption) with the vision patches before the segmentation head.

## Features
- **Automatic Mixed Precision (AMP)** for faster training.
- **Early Stopping** to dynamically halt training when validation mIoU plateaus.
- **Weights and Biases (WandB)** integration for tracking experiment metrics (Loss, mIoU, Precision, Recall, F1-Score).
- Detailed **Ablation Studies** comparing different caption generation sources.

## How to Run
1. Ensure dependencies are installed (`pip install torch torchvision pandas numpy matplotlib wandb`).
2. Run `jupyter notebook` and open `phase3_proposal/phase3.ipynb`.
3. Follow the cells sequentially. Make sure to log into your WandB account when prompted.

## Results
The multi-modal architecture demonstrates significant qualitative and quantitative improvements, particularly in distinguishing spectrally similar classes like "Grass" and "Crop", proving the value of semantic text priors in remote sensing segmentation.
